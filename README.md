# E-commerce Sales Analysis

## Project Overview
Analyzing online retail data to understand sales trends, product performance, and customer purchasing behavior.

## Objectives
- Analyze overall sales performance.
- Identify top-selling products.
- Explore sales trends.
- Generate insights to support business decisions.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- Power BI (for dashboard visualization, when completed)

## Project Workflow
1. Data loading
2. Data cleaning
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Business insights and recommendations

## Dataset
Online Retail dataset.
